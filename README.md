# Kenya Industry Opportunity Radar

Which industry groups should a Clients & Markets team prioritise in FY27? A scorecard built **only from official, public Kenyan data**: KNBS Quarterly GDP (Q1 2026), CBK Bank Supervision Annual Report 2025, CBK Credit Officer Survey (June 2026) and the KNBS Economic Survey 2026.

**Start here:** `docs/executive_summary.md`, then `dashboard/opportunity_radar_dashboard.html` and `model/opportunity_radar_model.xlsx`.

| Folder | Contents |
|---|---|
| `raw/` | Text extracted from the source PDFs, with `SOURCES.md` |
| `data/` | Tidy CSVs parsed from those sources |
| `analysis/` | Extraction, model, workbook, dashboard and comms builders |
| `outputs/` | Industry scorecard (CSV) and model settings |
| `model/` | Excel model with live formulas and a reconciliation sheet |
| `dashboard/` | Interactive HTML dashboard (adjustable weights) |
| `briefs/` | Ten industry briefs with client conversation starters |
| `comms/` | Draft thought-leadership article, content calendar with post copy |
| `docs/` | Summary, methods, CV bullets, cover letter, interview Q&A |

Reproduce: see `docs/methods_appendix.md`.

**Limits:** industry groups are an analyst grouping; two groups lack bank-sector data (neutral credit score); GDP data runs to Q1 2026; the ranking is a prioritisation aid, not a forecast.
